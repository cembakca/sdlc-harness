# Spec — Improve the notification experience

## Summary
Users complain that notifications are noisy and not very useful. We should make
them better and more relevant, and generally improve how the product feels when
something changes.

## Acceptance criteria
1. Notifications should be more relevant to the user.
2. The system should not spam people.
3. Performance should be good.
4. The UI should look clean and modern.
5. We may also want to revisit the email templates, and possibly the digest,
   depending on what we find.
